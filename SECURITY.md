# Security Policy

This repository is intentionally vulnerable and exists only for authorized GitHub Advanced Security and OWASP training.

Do not deploy this application publicly. Do not connect it to production data, real accounts, real secrets, production databases, or shared corporate systems.

## Training Scope

The vulnerable code paths are marked with `TRAINING VULNERABLE PATTERN` comments. The fixed examples are marked with `TRAINING FIXED PATTERN` comments.

## GitHub Security Features

Enable these repository or organization settings after importing the repo:

- GitHub Advanced Security
- CodeQL code scanning
- Dependabot alerts
- Dependabot security updates
- Secret scanning
- Secret scanning push protection

The repo also includes a Gitleaks workflow for an Actions-based secret scanning demo.
